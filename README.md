# Milestone 1 – Spotify Data Analysis

## Project Overview
This project focuses on analyzing a Spotify dataset using Python and Pandas. The objective is to perform data transformation, handle missing values using mean imputation, generate meaningful insights, and visualize the results.

## Dataset
Spotify dataset (`spotify.csv`).

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
1. Dataset reading using Pandas.
2. Understanding the dataset.
3. Data transformation.
4. Identifying and handling null values using mean imputation.
5. Generating meaningful insights.
6. Visualizing the results using charts.

## Files Included
- `milestone1.ipynb` – Complete Python notebook.
- `spotify.csv` – Dataset used for analysis.
- `README.md` – Project overview.

## Conclusion
This project provides practical experience in data analysis, data transformation, missing value handling, insight generation, and data visualization using Python.
